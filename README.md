# Weather App 🌤️

A modern, responsive weather app built with **HTML, CSS, and JavaScript**.  
Features include:
- Current weather for any city
- Haze, rain, snow, clear, and other weather conditions supported
- Dynamic weather icons
- Background changes according to weather
- Smooth modern animations
- Geolocation: “Find my weather”
- Responsive design for mobile and desktop

### How to Use
1. Open `index.html` in a browser
2. Type a city name to get current weather
3. Or click “Find my weather” to use your location

### Example Cities
- Clear: Los Angeles, Cairo
- Rain: London, Mumbai
- Snow: Moscow, Denver
- Haze: Beijing, Delhi
- Clouds: Tokyo, New York

### Tech Used
- HTML, CSS, JavaScript
- OpenWeatherMap API for weather data
- CSS animations & transitions
